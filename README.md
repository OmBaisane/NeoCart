# NeoCart 🛒 - E-Commerce Storefront (Legacy Version)

> A foundational full-stack e-commerce application built to master server-side logic, relational databases, and user session management.

## 💡 About The Project
This project serves as my Version 1 (V1) e-commerce build. I developed NeoCart to get hands-on experience with core web architecture, MVC-like structuring, and frontend-to-backend integration before transitioning to modern JavaScript frameworks. 

## ✨ Key Features
* **Secure Authentication:** User registration, login, and secure session management.
* **Dynamic Product Catalog:** Product listing, search functionality, and category filtering.
* **Cart & Order Management:** Session-based shopping cart and complete order processing flow.
* **Admin Dashboard:** Centralized panel for managing product inventory and tracking user orders.
* **Optimized UX:** AJAX-based interactions for seamless, page-reload-free experiences.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Bootstrap, JavaScript (Vanilla + AJAX)
* **Backend:** PHP (Core)
* **Database:** MySQL

## 🚀 Future Roadmap (NeoCart V2)
Currently focusing on advanced JavaScript architectures. This project is scheduled to be entirely rebuilt as a modern Single Page Application (SPA) utilizing the **MERN Stack** (MongoDB, Express, React, Node.js) with features like a third-party payment gateway integration and advanced state management.
